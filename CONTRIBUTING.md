# Contributing

## Development setup

```bash
git clone <your-fork>
cd paper-tool
python -m venv .venv
.venv\Scripts\activate        # Windows; use `source .venv/bin/activate` elsewhere
pip install -r requirements-dev.txt
python -m unittest discover
```

The suite is fully offline (apart from its loopback HTTP test server): it uses temporary directories and mocked HTTP. A
few PDF-fixture tests skip themselves when `reportlab` is absent.

## Ground rules

- **No network in tests.** Do not add tests that call Crossref, OpenAlex,
  Unpaywall, Zotero or a real browser.
- **Zero heavy dependencies at runtime.** Only `pypdf` is required. The Excel
  ledger is written as raw OOXML with the standard library.
- **Explicit writes.** `fetch` and `batch` download without Zotero.
  Zotero writes require `--zotero --collection`. Never create, delete or move a
  Zotero collection; never overwrite an existing PDF or attachment.
- **Never commit credentials or personal data.** No PDFs, no checkpoints, no
  browser profiles, no `.local-auth`, no private reference lists. See
  `.gitignore`.
- **Encoding.** Source and docs are UTF-8. The double-click Windows launcher
  `generate-report.cmd` is **GBK + CRLF** and is generated by
  `python _gen_launcher.py`; edit the template in that script, not the `.cmd`.
  Avoid characters outside GB2312 in the generated text.
- **Paths.** Use `Path(__file__).resolve().parent` or CLI arguments. Never
  hard-code a home directory, a username, a Zotero collection path or a
  machine-specific output folder in source, tests or docs.

## Adding a paper status

New statuses must be added to `STATUS_RANK`, `progress_snapshot()` and
`deliverables.py`, with an offline test that asserts the reporting semantics.

## Pull requests

Describe the behaviour change and include the output of
`python -m unittest discover`. Keep commits focused; do not include batch data.

CI runs tests and wheel/source builds on Linux, Windows and macOS with Python 3.10 and 3.13. Release artifacts must include LICENSE; machine-specific notes belong in ignored `.local/`.
