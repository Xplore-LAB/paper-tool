# 执行策略与来源边界

策略版本为 2.0。远程请求由任务专属 SafetyGuard 管理，包括元数据、OA 下载和重定向跳转；本机回环接口不与远程来源混用额度。

默认每来源并发为 1，请求完成后至少间隔 30 秒；每篇最多 2 次自动重试；首批 5 篇，后续每批 10 篇；运行预算 7200 秒，累计 PDF 传输预算 2 GiB。失败下载的传输量也计入预算。可以收紧预算，不能通过计划参数放宽上限或缩短间隔。

来源按主机归组，并显式合并已知别名，例如 ScienceDirect、Elsevier API 和 PDF 域名共用来源。该规则作用于一个任务，不是整台机器或多台机器的统一出口限流器。

- 429：解析秒数或 HTTP 日期形式的 Retry-After，暂停该来源，在剩余重试和任务预算内等待。
- 401/403：暂停该远程来源；不会继续尝试同来源的其他 URL。
- 来源失败不删除其他已完成结果，也不禁止独立来源继续工作。
- 取消、时长或下载预算耗尽：保存任务状态，报告 BATCH_PAUSED 及具体停止原因。

机构浏览器是可选路径，仍需 Node.js、Playwright、Chrome/Edge 与已有合法访问权限。V2 未修改浏览器后端：Python 管理浏览器操作入口、操作超时和返回文件字节；浏览器内部页面资源请求没有逐个接入 Python 调度。严格要求逐请求计量的任务使用 `--oa-only`。不要将操作边界管理描述为所有浏览器请求均已受控。

请用户自行完成登录或验证，不收集密码、不导出 Cookie，不绕过付费墙或验证挑战。

SHA-256 用于发现损坏和意外变动，不是发行者数字签名。应从可信发布渠道获取完整技能包。
