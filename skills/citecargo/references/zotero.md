# Zotero 授权与幂等

Zotero 10+ 需开启本机接口并在首次写入时授权。本机接口只能通过回环地址使用；跨电脑通过 SSH 转发，不公开未认证接口。

下载任务默认不连接 Zotero。用户明确要求归档且给出目标分类后，在 plan 中加 `--zotero --collection`。job 还需 `--allow-zotero` 认可这一固定范围。该开关不替代用户授权，用户已明确授权时也不应再次强制询问。

只用已有分类，不创建、删除或移动分类。按 DOI 复用条目并增量加入分类，不覆盖用户题录，不删除已有文件。附件恢复使用原记录与 MD5 前置条件，无法确定原附件健康时保留待复核。

仅保存题录使用 `--metadata-only`。只完成题录不能报告 PDF 下载成功。归档失败时报告 ZOTERO_WRITE_FAILED 并保留本地文件，网络接口成功的模拟测试不能代替真实桌面验收。
